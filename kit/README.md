# Live Device Kit

A design system for HTML mocks that look exactly like Ableton Live 12 devices. Design only: how to
build a mock as a real Max for Live device lives in m4l-loop.

- Source of truth: this repo. Published view: https://claude.ai/artifact/Uww7TVHaywVZU3KgZiKhMs
- Everything under `project/` is the kit (layout of the "Design System" artifact type). Start at `project/README.md`.
- `index.html` and `SKILL.md` belong to the artifact type and are not tracked.

## Publishing
Ask Claude to "publish the kit": it publishes the changed `project/` files to the artifact URL above,
then `project/design-system.json` last with a new `lastChange`.
