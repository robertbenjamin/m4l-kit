# Live Device Kit

A design system for HTML mocks that look exactly like Ableton Live 12 devices. Design only: how to
build a mock as a real Max for Live device lives in `../loop`.

- An older snapshot is published at https://claude.ai/artifact/Uww7TVHaywVZU3KgZiKhMs. It isn't kept in sync: this folder is the source.
- Everything under `project/` is the kit (layout of the "Design System" artifact type). Start at `project/README.md`.
- `index.html` and `SKILL.md` belong to the artifact type and are not tracked.
